# QuizMaster Pro

## HOW TO RUN (Windows)

### Option 1 — Double Click (Easiest)
Double-click `run.bat` — it does everything automatically.

### Option 2 — Manual
1. Open Command Prompt in this folder
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open browser: `http://127.0.0.1:5000`

## IMPORTANT
- Always open via `http://127.0.0.1:5000` — NOT by opening HTML files directly
- Interview Prep: `http://127.0.0.1:5000/interview`
- Stop server: Ctrl+C in terminal
